# Hi, I'm Jeffrin Sam 👋

I'm a Robotics and AI researcher working to unlock the **AGI moment — the "GPT movement" — of the agentic robotics era** in humanoid robotics.

🔭 **Current focus:** World Action Models for robotics — pairing generative world models like NVIDIA Cosmos with JEPA-style predictive architectures so humanoids can plan, act, and self-correct in a closed loop: when the robot fails, it learns from its own generated demonstration videos.

🌱 Currently: Researcher (World Action Model) at MWS AI, and Graduate Student Researcher (Physical AI) at Skoltech ISR Lab.

## 🚀 Featured projects

- **[GENESIS](https://github.com/JeffrinSam/GENESIS)** — Video-conditioned robot learning; agentic video generation flows into navigation and manipulation. Companion codebase for the "Action Agent" paper (IROS 2026).
- **[G1 Sim Personal](https://github.com/JeffrinSam/G1_Sim_Personal)** — Modular MuJoCo simulation and control framework for the Unitree G1 humanoid with BrainCo hands: ONNX RL policies for standing/walking, plus a closed-loop VLA manipulation inference stack.
- **[G1 with BrainCo Hand](https://github.com/JeffrinSam/g1-with-brainco-hand)** — MuJoCo simulation and control scripts for the Unitree G1 with BrainCo dexterous hands: whole-body control, RL training, and VLA policy inference.
- **[Unitree RL MJLab Tutorial](https://github.com/JeffrinSam/unitree_rl_mjlab_tutorial)** — Reinforcement learning implementation tutorial for Unitree robots, built on MuJoCo.
- **[Synthetic Data for Unitree G1](https://github.com/JeffrinSam/JeffrinSam_G1)** — Synthetic joint data for Unitree H1/G1 via imitation learning in Isaac Lab, enhanced with Cosmos, used to deploy GR00T N1.5 for pick-and-place.
- **[VTOL Tailsitter Unity SIL](https://github.com/JeffrinSam/VTOL-Tailsitter-Unity-SIL)** — Unity-based VTOL tail-sitter simulation for SIL testing and autonomous flight validation. Underpins the YawSitter paper (IEEE ROBIO 2025).
- **[JEPA Study](https://github.com/JeffrinSam/JEPAstudy)** — A zero-to-mastery JEPA study guide covering JEPA, V-JEPA 2, VLA models, and world models for embodied AI.
- **SONIC: Whole-Body Humanoid Control** — Among the first known external deployments of NVIDIA's [GEAR-SONIC](https://nvlabs.github.io/GEAR-SONIC/) whole-body control stack, reproduced and validated on a real humanoid.

## 🤗 Honorable mention

- **[GR00T-N1.7-G1-BrainCo-Pick](https://huggingface.co/JeffrinSam/GR00T-N1.7-G1-BrainCo-Pick)** — Fine-tuned NVIDIA GR00T N1.7 for the Unitree G1 + BrainCo hands, trained on 1,598 real-robot pick-and-place episodes; predicts 26-DOF arm and hand commands from a single head camera.
- **[Cosmos3-Nano-G1-BrainCo-PolicySFT](https://huggingface.co/JeffrinSam/Cosmos3-Nano-G1-BrainCo-PolicySFT)** — Fine-tuned NVIDIA Cosmos3-Nano that jointly generates a video of the G1 executing a task and the corresponding 26-DOF joint-angle trajectory at 15 Hz.
